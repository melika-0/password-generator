# Password Generator

A simple command-line password generator written in Python.

## Features

* Custom password length
* Uppercase and lowercase letters
* Numbers and symbols
* Random password generation
* Input validation

## Technologies

* Python
* `random` module

## How to Run

```bash
python password_generator.py
```

## Concepts

* Functions
* Loops
* Dictionaries
* Lists
* Exception handling
* Random number generation
